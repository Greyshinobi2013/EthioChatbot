# Troubleshooting Guide

## Webcam Not Opening

Possible Causes:

- Camera already in use
- Invalid camera index
- Driver issue

Recommended Action:

- Verify camera device
- Restart application

---

## Whisper Model Not Loading

Possible Causes:

- Missing model
- Corrupted model cache
- Insufficient memory

Recommended Action:

- Re-download model
- Verify available RAM

---

## Face Recognition Failure

Possible Causes:

- No enrolled users
- Poor lighting
- Camera quality

Recommended Action:

- Re-enroll face
- Improve lighting

---

## Wake Word Not Detected

Possible Causes:

- Microphone issue
- High noise level

Recommended Action:

- Verify microphone
- Reduce background noise

---

## Audio Playback Failure

Possible Causes:

- Missing file
- Unsupported format
- Audio device issue

Recommended Action:

- Verify file path
- Verify audio device

---

## Playback Does Not Resume

Possible Causes:

- Playback position lost
- Interruption handler failure

Recommended Action:

- Validate playback state
- Check logs

---

## Application Becomes Unresponsive

Possible Causes:

- Thread deadlock
- Blocking operation

Recommended Action:

- Review logs
- Verify thread synchronization
